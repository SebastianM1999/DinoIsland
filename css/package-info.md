# css
> Runtime presentation for the plain-DOM shell, dialogs and HUD. Game rules and input behavior stay in JavaScript.

- `main.css`: font/tokens, shell primitives, settings, pause and lobby base layouts.
- `menu.css`: home slideshow, navigation, expedition picker and home dialogs.
- `expeditionTheme.css`: shared field-journal paper material system and responsive menu/dialog skins. Loaded by `index.html`; rules are scoped to `body.island-theme` and specific dialog classes so late HUD styles cannot override the theme or alter the live HUD. Uses CSS surfaces, not reference-image backgrounds; the slideshow and game scene remain visible. Paper surfaces use CSS water stains, creases, folded corners and shadows with the small repeating journal-grain.svg texture. Irregular fixed-depth tears and chipped corners are clipped on isolated negative-z paper pseudo-elements, never on content. Shadow filters follow the paper silhouette; scrolling fallback fills only the content box so it cannot close the edge cutouts. The legacy external foliage overlays are hidden; faint leaf illustrations live below controls inside the frames. Inventory, stations and header close buttons share the letter-paper treatment; skill layout remains in skills.css. Shared Lucide icon sizing outranks lazy HUD SVG rules; icons use currentColor and do not receive input.
- `hud.css`: live HUD, inventory, mission board and station dialog base layouts; loaded lazily by the HUD and home previews.
- `skills.css`: the native tinted-paper skill tree, its hosts, equal-sized centered tiles and descriptions. Width caps at 1480 px; compact viewports reduce decoration, and very small windows scroll instead of clipping controls. Skill SVG sizing must outrank generic `.hud svg` regardless of stylesheet order.
- `loading.css`: lightweight expedition loading photograph/phase presentation.
- `journalScroll.css`: responsive illustrated folio margins, Caveat handwriting, numbered paper tabs and stitched leather/rope edging. Desktop frames reserve a gutter and expand their width caps; short/narrow windows hide it. Container queries simplify artwork within short dialogs. The margin is inert and paints below controls, with no viewport measurements or runtime animation.

Keep real text and controls in the DOM. Preserve native keyboard focus, disabled/selected states, setting slider fill values, inventory slot counts and item visibility. Dialogs stay centered and capped rather than stretching across ultrawide monitors. Verify both initial home loads and transitions into play because stylesheet order changes there. Never replace the slideshow or live scene with a baked reference backdrop.
